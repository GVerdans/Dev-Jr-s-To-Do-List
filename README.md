# ✅ Jr's Todo List v2.0

🇧🇷 **Português** | [🇺🇸 English](#-english-version)

Projeto de **Todo List com Pomodoro Timer**, desenvolvido com JavaScript moderno e Webpack, focado em organização de código, estado da aplicação e persistência de dados.

🔗 **Demo (GitHub Pages)**  
> [Live Demo](https://gverdans.github.io/Dev-Jr-s-To-Do-List/)

---

## 📌 Funcionalidades
- ➕ Adicionar tarefas
- ❌ Remover tarefas
- ✔️ Marcar tarefas como concluídas
- 💾 Persistência com **localStorage**
- ⏱ Pomodoro Timer configurável (20 / 25 / 30 minutos)
- ♻️ Estado sincronizado com o DOM

---

- JavaScript (ES6+)

- HTML5
- localStorage
- Git & GitHub
